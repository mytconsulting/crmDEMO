# Plantillas para Agentes IA (WhatsApp & Instagram)

Estas plantillas definen el contexto que el agente IA usara para conversar con tus leads.
Son validas tanto para el agente de WhatsApp como para el de Instagram.

## Como usar

1. Abre cada plantilla (.md)
2. Rellena los campos marcados con `[...]`
3. Elimina las lineas de ejemplo que no apliquen a tu negocio
4. Sube el contenido desde el panel "Configuracion Chatbot" de tu CRM

## Plantillas disponibles

| # | Archivo | Que define | Obligatorio |
|---|---------|-----------|-------------|
| 1 | `01-identidad-y-voz.md` | Tono, expresiones, emojis, formato de respuesta | Recomendado |
| 2 | `02-negocio.md` | Oferta, puntos de venta, objeciones, prueba social | Recomendado |
| 3 | `03-calificacion.md` | Cliente ideal, red flags, campos clave, scoring | Recomendado |
| 4 | `04-disponibilidad.md` | Horarios, reuniones, zona horaria | Recomendado |
| 5 | `05-faqs.md` | Preguntas frecuentes con respuestas | Opcional |
| 6 | `06-ejemplos-conversacion.md` | Conversaciones reales de referencia | Opcional |

> Ninguna plantilla es obligatoria. Si no subes alguna, el agente funcionara
> con las que tenga disponibles. Cuantas mas rellenes, mejor sera la calidad
> de las respuestas.
